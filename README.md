# MCQ Pace Timer

A one-minute-per-question focus timer for MCQ practice sessions.

- **Enter** (or click the dial) starts a question; press again to log it and reset.
- Turns amber in the last 10 seconds and red once you pass 1:00, with a chime and overtime counter.
- Ticking sound (can be muted), running average, last-5 average, pace chart and a clearable log.
- Dark (default) and light themes, switched with the button in the top corner.
- **Esc** discards the running question. Your log is saved in your browser.

Live: https://ahmadmqarni.github.io/mcq-pace-timer/

Single static file (`index.html`), no build step.
